These routes were observed with Even 2.3.2 in October 2026. Labels and versions can change; inspect the live screen. This reference concerns the iPhone app, not the separate Developer Hub website. Apply any project-specific operating skill and release rules as well.

## Choose the intended route

| Purpose | Route | Check |
| --- | --- | --- |
| Installed app | Bottom Home/house tab, then the installed app card icon | Read the app version after opening |
| Store and app management | Even Hub/four-square tab, top-right avatar, My plugins | App name opens details; Open launches |
| Uploaded developer build | My plugins, top profile row/chevron, Developer hub, lower In development app row | Read version and Beta label; do not substitute prototype mode |
| URL prototype | Developer hub, Prototype mode, QR scan, cannot-scan link | Use only the intended authorized URL; do not press Start just to inspect the field |

The profile row was observed to navigate to Developer hub. Do not assume it edits account information merely because of its appearance.

## Stop, reopen and update

For the observed Dot Link host, the top-left diagonal-arrow control opened a confirmation explaining that the running function would stop. Choosing Exit returned to the originating app list. The top-right ellipsis exposed uninstall; it was not a restart control. Stop only when it is within the user's task, then reopen from the same route and verify the version and connection state.

An Update badge changes the tested version. Do not press it just to open the installed app. For a newly available developer build, leaving Developer hub and entering it again was the user-confirmed refresh procedure. Inspect the resulting Open/Update control; do not uninstall to refresh. After an authorized update, reopen and verify the target version.
